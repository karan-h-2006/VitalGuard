## Capture limitations

- The current product has no upload control, so there is no upload state to capture.
- The password update screenshots use a synthetic validation response; no real password is changed.
- Data is mocked at the API boundary; this is a UI walkthrough, not proof of live hardware, email delivery, or a production audit write.
